# Data Types

There are two types.

- Primitive Data Types
- Reference Data Types

## Primitive Data Types

- String: Sequence of characters. Must be is quotes or backticks.
- Number: Integers as wel as floating-point numbers.
- Boolean: Logical entity/true or false.
- Null: Intentional absence of any object value.
- Undefined: A variable that has not yet been defined/assigned.
- Symbol: Built-in object whose constructoor returns a unique symbol.(ES6)
- BigInt - Numbers that are greater than the number type can handle.

## Reference Data Types

Reference types or "objects" are a non-primitive value and when assigned to a variable, the variable is given a reference to that value.

Object literals, arrays and functions are all reference types.
